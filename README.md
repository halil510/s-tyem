# Sütyem Pro

Süt toplama ve yem satışı yapan işletmeler için cari (müşteri) takip uygulaması.

- Günlük sabah/akşam süt girişi (tek cari veya tüm cariler için hızlı giriş), terazi bağlantısı (BLE / Klasik Bluetooth / Wi-Fi)
- Yem verişi, cari bazlı aylık süt ve yem fiyatları
- Canlı cari hesap ekstresi: süt alacağı, yem borcu, ödeme ve tahsilat; Excel / PDF / WhatsApp
- Yedekleme: DB dosyası, JSON, Excel, cihazdan cihaza Bluetooth / Wi-Fi aktarım

## Geliştirme

```bash
flutter pub get
flutter test      # tüm testler geçmeli
flutter analyze
flutter run
```

Mimari kurallar, iş mantığı, yapılanlar ve sıradaki işler için **[SUTYEM.md](SUTYEM.md)** dosyasına bakın.
